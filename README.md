# RuleTray

一个在 Windows 托盘里切换 AI 任务规范的小工具。

我平时用 AI 讲题和记笔记，慢慢攒了不少要求。AGENTS.md 越写越长，AI 拿到它之后，还要去读讲解规范、笔记规范。做完一道题，开个新对话，又读一遍。

所以我想到了在托盘里选项目、选任务。比如这次要“讲解并记笔记”，就提前把这份规范写进 AGENTS.md，再打开原来的客户端提问。下次做别的，选一下就换过去。

代码是我让 AI 写的，目前也在自己用。做这个主要是想少花一些重复加载规范的额度，不过到底能省多少，还要再测，暂时没有数字。

## 怎么用

配置好以后，双击启动，右下角会多一个托盘图标，可能在“小三角”里面。

1. 右键选项目，项目没变就不用重选。
2. 再右键选任务。
3. 回到 AI 客户端，在对应项目里开新对话，照常提问或发图片。

选“其他任务”会恢复项目的完整默认规则。选项目只是浏览，点任务才会改文件；客户端里的项目仍要自己选对。

我把“讲解并记笔记”放在一起，是因为讲题时往往也会解释概念、出小题，最后还要记下来。这些要求就放进同一份规范，不用讲到一半再去找另一份。其他任务也是这个思路：**一次要做的事，尽量用一份完整规范说清楚。** 所有任务共同遵守的要求保留在文件前面，切换时只换任务部分。

## 下载后，还需要整理自己的规范

这个项目只是一个简单的框架，包里有程序和配置示例，没有一套适合所有人的现成规范。我的任务分类也不一定适合你。

第一次用，要先看看自己经常让 AI 做什么，把现有要求整理一下，分好任务，再配置到菜单里。重复或冲突的规则可以一起处理；还没写过规范的话，就从平时提的要求开始。这个过程可以让你的 AI 来做，你把需求说清楚，看看它整理得对不对就行。

目前没有 exe，需要 Python 3.10+。不想自己装环境的话，可以下载、解压源码，把下面这段话和项目一起交给能操作本机文件的 AI：

> 帮我装好这个 RuleTray。先读 README.md 和 PLAYBOOK.md，问我用什么客户端、要用在哪个项目、现有规范放在哪里。根据我常做的事情整理规范、划分任务，一份任务对应一份完整规范，给我看过再改。然后完成安装和配置，实际试一下切换、恢复，以及客户端新对话能不能读到。最后给我一个能双击启动的入口，告诉我平时怎么用。

安装细节在 [PLAYBOOK](PLAYBOOK.md)。规范内容需要你确认，路径也需要问清楚，不能让 AI 猜一个位置就覆盖旧文件。

## 使用前留意一下

托盘目前只支持 Windows。我在自己的 Codex 上试过，新对话能读到切换后的规范。其他支持本地规则文件的 Agent 也可以尝试适配，具体读哪个文件、大小限制是多少、什么时候重读，让安装的 AI 按客户端核对，见 [ADAPTERS](ADAPTERS.md)。

一个项目只有一份当前规则，所以不要一边开着几个不同任务，一边来回切换。这更适合做完一个短任务，再开新对话做下一个。改了文件，也不代表已经打开的对话会跟着更新。

要停用并恢复默认规则，选菜单里的“停用并恢复所有项目…”。直接退出只会关掉托盘，当前规则仍然保留。文件被其他程序改过时，工具会暂停覆盖，避免直接冲掉改动。

缓存还取决于客户端和服务端，文件内容不变也不能保证命中。我会继续用一段时间，再补实际结果。遇到问题可以提 Issue，说明操作过程和出现的情况。
